# Card images (optional)

Drop image files here. Any card without an image is drawn in code instead.

Formats: `.png` `.jpg` `.jpeg` `.webp` `.svg`. Best size: 2:3 portrait, for example 240 x 360 px.

| Cards | File names |
|---|---|
| Numbers | `red-0` … `red-9`, and the same for `yellow-`, `green-`, `blue-` |
| Actions | `red-skip`, `red-reverse`, `red-draw2` (and the same for each color) |
| Wilds | `wild`, `wild4` |
| Card back | `back` |

Example: `red-7.png`, `blue-draw2.webp`, `wild4.svg`, `back.png`

Only use art you made yourself or that has a license allowing it.
The official UNO card designs belong to Mattel.
